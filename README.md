# César Huamaní — Portafolio profesional

Sitio web personal de economía aplicada, investigación cuantitativa y ciencia de datos.

**URL prevista:** https://cesarahn.github.io/

## Publicar en GitHub Pages
1. Abrir **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Elegir la rama **main** y la carpeta **/(root)**. Guardar.
4. Comprobar la web una vez que GitHub indique que está publicada.

## Archivos
- `index.html`: estructura y textos de la página.
- `styles.css`: estilos, diseño y vista móvil.
- `script.js`: menú y detalles de interacción.
- `favicon.svg`: icono de pestaña.
- `.nojekyll`: indica a GitHub Pages que publique los archivos directamente.

## Personalización pendiente
- **Fotografía:** actualmente se muestra el avatar público de GitHub. Para usar una fotografía definitiva, guardar la foto autorizada como `foto.jpg` en la raíz y sustituir en `index.html` el valor del atributo `src` de `id="portrait-photo"` por `foto.jpg`.
- **Proyectos:** las tarjetas actuales son descripciones de áreas de trabajo, no resultados ni publicaciones oficiales. Enlazar proyectos públicos cuando se seleccionen.
- **Formación, CV y contacto:** agregar solo la información profesional que se decida hacer pública.
- **Literatura:** la sección se encuentra marcada como «Próximamente». Más adelante enlazará al repositorio secundario.

**Tecnología:** HTML, CSS y JavaScript puro; sin frameworks, licencias comerciales ni servicios pagos.

**Diseño:** implementación original con estética de portafolio contemporáneo y paleta azul profundo/turquesa; no contiene código ni archivos de la plantilla GoFolium.
